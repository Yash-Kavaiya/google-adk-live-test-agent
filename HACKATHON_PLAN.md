# Hackathon Plan — Google Devpost Agent Live

## Project
**LiveTest Agent** — Real-time interview + hackathon coach using Google ADK Live API.

## Goal
Help candidates practice with live voice interaction and receive actionable feedback per answer.

## Milestones

### M1: Working MVP (Day 1)
- [x] Start from ADK live template
- [x] Define coaching prompt and interview flow
- [ ] Run end-to-end locally (client + server)

### M2: Differentiators (Day 2)
- [ ] Role-based tracks (AI Engineer / SDE / Data / PM)
- [ ] Structured scoring rubric (clarity, depth, confidence, correctness)
- [ ] Weak-area tracking and adaptive follow-up questions

### M3: Demo polish (Day 3)
- [ ] Session summary report (markdown)
- [ ] Prompt tuning for concise responses
- [ ] Demo recording + screenshots
- [ ] Devpost submission draft

## Suggested judging narrative
- Real-time multimodal interaction (live audio + transcript)
- Immediate personalized coaching loop
- Practical utility for interview and pitch readiness
- Built with ADK + modern full-stack template

## Stretch goals
- [ ] Resume-aware question generation
- [ ] Domain-specific mock rounds (NVIDIA / GCP / Dialogflow)
- [ ] Team interview mode (panel style)
